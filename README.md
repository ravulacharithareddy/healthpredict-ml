# HealthPredict — Multiple Disease Prediction Using Machine Learning

## Overview

HealthPredict is an educational and research-focused full-stack web application that uses machine learning to estimate the likelihood of multiple diseases — **Diabetes**, **Heart Disease**, **Parkinson's Disease**, and **Liver Disease** — from health parameters entered by the user.

The platform is designed to demonstrate how machine-learning models can be applied to healthcare screening in an accessible, transparent, and privacy-first way. All predictions run in the browser; no health data is stored or transmitted. The prediction layer is structured so that a real Python (Flask/FastAPI) backend serving trained models can be connected with minimal changes.

> **Disclaimer:** HealthPredict is an educational and research tool. Predictions are generated by machine-learning models and are **not a medical diagnosis**. Always consult a qualified healthcare professional.

## Features

- **Home page** — Modern healthcare/AI hero section with project title, subtitle, explanation, and a "Start Prediction" call-to-action.
- **Prediction modules** — Cards for each disease with name, short description, and a "Predict Now" button.
- **Prediction forms** — A separate, validated form for each disease with clearly labelled input fields, units, and helper text.
- **Prediction results** — Clear positive/negative status, a model-confidence bar, risk level (Low / Moderate / High), key contributing factors, and an educational-use disclaimer.
- **About page** — Explains the machine-learning approach, purpose, how prediction works, and technologies used.
- **Contact page** — A simple, validated contact form with project information.
- **Responsive design** — Optimized for mobile, tablet, and desktop.
- **Smooth animations** — Fade-up, scale-in, and micro-interactions throughout.
- **Accessible** — Clear typography, sufficient color contrast, keyboard-friendly navigation.
- **Privacy-first** — All predictions run client-side; no data leaves the browser.

## How Prediction Works

1. **Input** — The user enters clinically-relevant health parameters for the selected disease.
2. **Feature scoring** — Each input is weighted by clinical significance and normalized. The model computes a combined score using a logistic-regression-style approach.
3. **Probability & risk** — A sigmoid function converts the score into a probability (0–100%). The result is classified as Low, Moderate, or High risk.
4. **Result** — The user sees a clear positive/negative result, a confidence bar, key contributing factors, and a reminder that the prediction is for educational purposes only.

### Connecting a Python Backend

The prediction logic in `src/lib/predict.ts` is isolated so it can be replaced with API calls to a Python backend. A typical integration:

```python
# FastAPI example
@app.post("/predict/diabetes")
def predict_diabetes(data: DiabetesInput):
    features = np.array([[data.glucose, data.bmi, ...]])
    probability = model.predict_proba(features)[0][1]
    return {"probability": float(probability), "positive": bool(probability >= 0.5)}
```
